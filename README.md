# 유행 디저트 카피캣 매장 분석 대시보드

SNS 유행 디저트 카피캣 매장의 상권 전이 및 생존 주기 분석
마라탕 · 요아정 · 탕후루의 패턴으로 모찌의 유행 기간을 예측합니다. (수도권)

## 폴더
- raw/ : 원본 데이터 (GitHub에 올리지 않고 구글 드라이브로 공유)
- python/ : 전처리·그래프 코드
- images/ : seaborn 그래프 PNG
- data/ : 대시보드용 JSON

## 규칙
1. 작업 전에 꼭 Pull 먼저
2. 각자 맡은 폴더만 수정
3. API 키는 절대 올리지 않기
4. 커밋 메시지는 한글로 짧게 (예: 탕후루 전처리 추가)
